# ⚔ .hack//G.U. Vol. 1//Rebirth — Native PC Recompilation

This folder contains the playable final product of the native Rust/.hack//G.U. recompilation.

## 🚀 How to Play
Double-click `play_vol1.bat` to launch the game.

### Game Flow:
1. **Title Screen & Main Menu**:
   - `[NEW GAME]`: Starts from the beginning of Vol. 1.
     - Streams the authentic pre-rendered CRI USM opening movie (`OP10000.usm`) in full-screen stereo.
     - Initializes character save data for Haseo (Lv 1 Adept Rogue).
     - Transitions directly to Mac Anu Central Plaza with 3D actors (Haseo, Iyoten, Asta).
     - Plays authentic cutscenes (`PM10100` $\to$ `PM10135` $\to$ `MM10145.usm` $\to$ `MM10210.usm` $\to$ `MM10220.usm` $\to$ `MM10230.usm` $\to$ `MM10240.usm`).
   - `[CONTINUE]`: Jump straight into Mac Anu Central Plaza exploration.
   - `[ALTIMIT OS]`: Access the in-game operating system (Emails, BBS forums, News, Login).
   - `[PROLOGUE MOVIE THEATER]`: Direct access to stream any of the 6 high-definition CRI USM full-motion cutscenes.
   - `[QUIT]`: Exit the game.

### Controls:
- **Movement**: `W` / `A` / `S` / `D` (or Left Analog Stick on Gamepad)
- **Camera Orbit**: Left Mouse Button + Drag (or Right Analog Stick on Gamepad)
- **Dialogue / Interaction**: `Space` / `F` / Left Click (or `A` Button on Gamepad)
- **Skip Cutscene**: `Esc` (or `B` Button on Gamepad)
- **Combat Attack**: `Space` (or `South / A` on Gamepad)
- **Rengeki Skill**: `Q` (or `West / X` on Gamepad)
- **Inventory / Quick Heal**: `H` (or `North / Y` on Gamepad)
- **Developer / Inspection Tools**: `F1` (toggles side panel if needed)
