## Reimplementation & "Bring Your Own Game" (BYOG)

1. **No Copyrighted Assets Distributed**:
   - This repository contains **zero** copyrighted assets, proprietary game code, 3D models, textures, dialogue text, audio files, or original binary executables.
   - All code in this repository is original code written for this project (Rust and Python tooling), based on
     reverse engineering for interoperability. Some layout data is computed at setup time by running parts of the
     user's own copy of the game code locally; none of it is shipped.

2. **User-Provided Assets**:
   - To use this software, users must legally own and provide their own copy of the game (*.hack//G.U. Last Recode* on PC / Steam).
   - Asset extraction scripts and tools included in this repository extract data locally on the user's computer directly from their own game install.
