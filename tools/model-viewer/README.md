# 🔍 .hack//G.U. 3D Model Viewer & Inspection Studio

A standalone GUI tool for inspecting models, animations, weapons, and stages extracted from `.hack//G.U.` files.

## 🚀 How to Use
1. **Launch**:
   - Double-click `launch_model_viewer.bat` (opens default character: Haseo 1st Form).
   - Or drag and drop any `.ccs` / `.css` model file directly onto `launch_model_viewer.bat`.
2. **Features**:
   - **Preset Quick-Load**: 1-click loading for all primary characters (Haseo, Atoli, Kuhn, Pi, Ovan, Bordeaux, Endrance, Tri-Edge, etc.), stages (Mac Anu districts, Arena, Hidden Forbidden Holy Ground), and weapons (Twin Blades, Broadswords, Scythes, Guns).
   - **Animation Controller**: Play, pause, scrub timeline, and step frame-by-frame through authentic character animations.
   - **Weapon Sockets**: Attach weapons to character bone sockets (`prop1`, `prop2`, `prop3`).
   - **GLB Exporter**: 1-click conversion to standard `.glb` format for Blender / Unity.
   - **CPK Archive Extractor**: Unpack `.cpk` files directly from retail game directories.
